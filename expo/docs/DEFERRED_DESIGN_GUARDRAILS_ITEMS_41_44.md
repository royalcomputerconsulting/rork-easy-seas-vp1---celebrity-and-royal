# Deferred design guardrails — items 41–44

These items remain deferred and must not be implemented until explicitly authorized.

## Non-negotiable preservation

- Preserve the existing Easy Seas logo, graphics, signature assets, and brand marks exactly as supplied.
- A visual migration must retain every existing action, filter, calculation, persistence path, route, accessibility label, and test identifier unless a separately approved functional specification replaces it.
- Establish behavior regression coverage before changing a screen. Screenshot approval alone is not sufficient.
