# Offers V2 data-parity gate

The V2 presentation may replace the production Offers route only when every production surface below has an equivalent visible V2 surface and the same handler.

- [ ] Portfolio totals: active offers, expiring soon, total value, eligible sailings
- [ ] Expiration command center: urgent, 0–7, 8–14, 15–30, no-expiry buckets and actions
- [ ] Search and filters: text, expiry, cabin, guests, minimum value, source, clear/apply
- [ ] Offer card: image, title, code, description, value, expiry, cabin, guests, score, eligible count
- [ ] Offer details: complete offer metadata and all eligible sailing rows
- [ ] Certificate relationships: certificate code, points/value, expiry, eligible sailings, download/view
- [ ] Casino relationships: casino offer metrics, source/evidence, activity links
- [ ] Recent activity: every production activity row and destination route
- [ ] Agent SEA / Ask My Data and Learn the system entry points
- [ ] Loading, empty, error, retry, sync, import, and no-results states
- [ ] Accessibility labels, stable test IDs, analytics hooks, and navigation contracts
- [ ] Loyalty card remains unchanged and is not owned by this redesign

The legacy screen remains the active route until this gate is complete.
